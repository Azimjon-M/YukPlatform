# shared — Umumiy ma'lumotlar

Barcha dasturlar (api, bot, web, mobile) bir xil ma'lumotlarni shu yerdan oladi.

- Viloyat va shaharlar, har xil yozilishi bilan: Фаргона / Fargona / Farg'ona / Фарғона
- Mashina turlari: tent, ref, ochiq, konteyner, labo, damas, isuzu...
- Turlar: fura / yengil / pochta / yo'lovchi
- E'lon modeli, ya'ni yuk ma'lumotining umumiy ko'rinishi
